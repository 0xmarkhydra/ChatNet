# ChatNet / SocCO

ChatNet là hệ thống giao tiếp đa ngôn ngữ với chat cá nhân và nhóm, Feed/Story, gọi thoại/video và dịch AI. Web/PWA và Electron dùng chung giao diện React. Mã nguồn cũng có ứng dụng Flutter.
